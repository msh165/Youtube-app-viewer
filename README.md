This application allows you to watch YT videos in an embedded manner.
I built this as I was genuinely scared of going to YT, based on the amount of time I used to waste.

This allows you to watch a video, without having to see your recommendations (Which we all know how enticing they can be)

Uses only flask and jinja

I have kept it open as I want to allow people to add things like uploading and storing multiple links for later viewing.

I wish to create a browser extension that stores links for you to work in collaboration with this.
